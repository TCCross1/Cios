# CIOS Brand Assets

This directory is the designated location for official CIOS brand assets
(logo, wordmark, favicon, color/typography tokens) once they are supplied.

**No official brand assets currently exist in this repository.** Do not
recreate, approximate, or generate a placeholder CIOS logo. When the
official logo file(s) are provided, place them here, e.g.:

- `assets/brand/logo.svg`
- `assets/brand/logo-mark.svg`
- `assets/brand/favicon.svg`

The visual design system (near-black/charcoal backgrounds, luminous cyan,
electric blue, refined violet, white/silver typography, glass surfaces,
neural/constellation motifs) is defined in the CIOS Master Context and will
be implemented in a future directive, not here.
